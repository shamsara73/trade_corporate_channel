# Task backlog – first vertical slice (Import LC issuance)

> Part of the agent guide: [AGENTS.md](../../AGENTS.md). Format: [task template](task-template.md). Spec: [Import Letter of Credit](../products/import-letter-of-credit.md).

The slice is ordered so each task has a test that proves it before the next starts. Tasks marked ∥ can run in parallel once their dependencies are done. T0 can start now: Java 21 and Thymeleaf are confirmed (Q18); the other stack choices are proposals that T0 may adjust with the owner's agreement.
