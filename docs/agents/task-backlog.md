# Task backlog – first vertical slice (Finance Standalone)

> Part of the agent guide: [AGENTS.md](../../AGENTS.md). Format: [task template](task-template.md). Spec: [Trade Finance and Repayments](../products/financing.md), message `TFFINNEW`. Evidence: [working samples](../reference/working-samples.md), section 2.

**Why this slice (decided by the project owner, 2026-10-23).** Finance Standalone is the only round trip proven against the bank's TI: `TFFINNEW` in, an immediate `ServiceResponse`, and `TFFINACK` out when the event is completed. Building it first means every layer can be tested against real behaviour. Import LC, the earlier first slice, follows the same pattern later (T12).

The slice is ordered so each task has a test that proves it before the next starts. Tasks marked ∥ can run in parallel once their dependencies are done.
