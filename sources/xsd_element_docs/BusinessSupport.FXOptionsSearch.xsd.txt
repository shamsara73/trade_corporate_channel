FXOptionsSearchRequest *()* - FX options search request. This service allows the bank to retrieve a list of available FX option contracts held for a customer that can then be taken-up when settling Trade Finance transactions.
  FXContractReference *(nillable: true, string Min: 1, Max: 20)* - FX option contract search filter.
  Customer *(nillable: true, string Min: 1, Max: 20)* - Customer mnemonic search filter.
  DealBranch *(nillable: true, string Min: 1, Max: 8)* - The deal branch mnemonic search filter.
  PurchaseCurrency *(nillable: true, string Min: 1, Max: 3)* - Purchase currency search filter.
  SaleCurrency *(nillable: true, string Min: 1, Max: 3)* - Sale currency search filter.
