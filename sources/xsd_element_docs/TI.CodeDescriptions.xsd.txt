CodeDescriptions *()* - Code descriptions maintenance Purpose: Allows language descriptions of codes to be added, updated or deleted e.g. GB C7 US - United states FR C7 US - L Etat Unis GB C5 CA - Current account FR C5 CA - Compte courant.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Language *(nillable: true, string Min: 1, Max: 2)* - Language.
  TypeCode *(nillable: true, string Min: 2, Max: 2)* - Type of static data item e.g C5 - Account type C7 - Country C8 - Currency. presenter's action, Response action, Claiming bank's action Instruction Group. Available values: 'C2'='Account officer', 'C5'='Account types', 'C6'='Analysis code', 'D4'='Base rates', 'CK'='Charge codes', 'CA'='Claiming bank's action', 'C7'='Country codes', 'C8'='Currency major unit name', '01'='Currency minor unit name', 'C4'='Customer types', 'OB'='Deal types', 'D5'='Differential rates', 'QA'='Export open account payment action', 'SA'='Export open account payment request action', 'DA'='Export open account payment request response action', 'GA'='Export open account payment response', 'FA'='Export open account presenter's action', 'OA'='Import open account payment action', 'EA'='Import open account presenter's action', 'AA'='Import open account response action', 'FS'='Instruction group', 'C1'='Language', 'YA'='Payment actions', 'PA'='Presenter's action', 'BA'='Reimbursement action', 'RA'='Response action', 'ST'='Supply chain finance programme sub-type', 'DH'='System parameters', 'CT'='Transaction codes', 'D1'='Transfer methods', 'TA'='Transfer presenter's action'.
  EntryIdent *(nillable: true, string Min: 1, Max: 10)* - Static data item key e.g US, USD , CA etc.
  Description *(nillable: true, string Min: 1, Max: 35)* - Language version of the description.
