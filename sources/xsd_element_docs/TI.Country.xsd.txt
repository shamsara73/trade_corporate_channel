Country *()* - Country maintenance: Allows countries to be added, updated or deleted.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Code *(nillable: true, string Min: 1, Max: 2)* - Code. Key to the country.
  ISOCode *(nillable: true, string Min: 1, Max: 2)* - ISO country code.
  FullName *(string Max: 35)* - Full name.
  AdjustNonBusinessDay *(logical)* - Indicates if date calculations should be adjusted to take into account non-business days. Reserved for future use. Boolean values.
  Tenor *(nillable: true, int)* - The tenor days can be defined for a country allowing country short, medium and long term risk to be categorized within Dept Limits.
