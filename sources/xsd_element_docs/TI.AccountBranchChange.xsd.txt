AccountBranchChange *()* - Account branch change. Purpose: Allows details of an account that is due to be changed from e.g. one branch to another during end of day processing. The message allows either a branch mnemonic or number to identify the old and new branch.
  MaintType *(string Max: 1)* -  Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  MainBankingEntity *(nillable: true, string Min: 1, Max: 8)* - Main banking entity.
  OldBranchMnemonic *(nillable: true, string Min: 1, Max: 8)* - Old branch mnemonic.
  OldBackOfficeAccNumber *(nillable: true, string Min: 1, Max: 34)* - Old Back office account number.
  NewBranchMnemonic *(nillable: true, string Min: 1, Max: 8)* - New branch mnemonic.
  NewBackOfficeAccNumber *(nillable: true, string Min: 1, Max: 34)* - New Back office account number.
