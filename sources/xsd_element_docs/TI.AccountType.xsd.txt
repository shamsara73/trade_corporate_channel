AccountType *()* - Account type maintenance: Purpose: Allows details of account types to be added, updated or deleted. Account types are referenced when opening accounts to ensure that accounts are opened with the correct attributes.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Code *(nillable: true, string Min: 1, Max: 10)* - Account type code.
  Description *(string Max: 35)* - Account type description.
  IsValidForFundsSettlement *(logical)* - Indicates whether accounts of this type are identified as valid for funds settlement i.e. that the account can be used for settlement of real funds. Applies to such accounts as Nostro, Vostro, Current accounts and internal settlement suspense accounts. Boolean values.
  IsInternal *(logical)* - Indicates whether accounts of this type are identified as internal accounts. Boolean values.
  IsContingent *(logical)* - Indicates whether accounts of this type are identified as contingent accounts. Boolean values.
  CreditInterestDaysBasis *(nillable: true, string Min: 1, Max: 1)* - The interest days basis to be applied to the any account opened using this account type when calculating credit interest. Interest days basis WARNING - SIGNIFICANT " " IN DOMAIN LIST MIGHT BE READ BACK AS NULL OR ''. Available values: '0'='0 - 365 day', '1'='1 - 360 day', '2'='2 - 365-6 day', '3'='3 - 360 / 30 day month', '4'='4 - 365 / 30 day month', '5'='5 - 365-6 / 30 day month'.
  DebitInterestDaysBasis *(nillable: true, string Min: 1, Max: 1)* - The interest days basis to be applied to the any account opened using this account type when calculating debit interest. Interest days basis WARNING - SIGNIFICANT " " IN DOMAIN LIST MIGHT BE READ BACK AS NULL OR ''. Available values: '0'='0 - 365 day', '1'='1 - 360 day', '2'='2 - 365-6 day', '3'='3 - 360 / 30 day month', '4'='4 - 365 / 30 day month', '5'='5 - 365-6 / 30 day month'.
