AttachedDocumentType *()* - Attached document type maintenance: Purpose: Allows details of Document types to be added, updated or deleted. These define the types of documents such as AWB - Airway Bill or BOE - Bill of Exchange that will be received by the bank as part of the Trade Finance business. The document types are then used when documents received are entered against an event.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Code *(nillable: true, string Min: 1, Max: 3)* - Code - e.g. BOL, AWB, BOE,INV.
  DocumentType *(string Max: 4)* - General document type. Expect to have multiple document keys for each type e.g. type = DOCU covers all the standard documents type = GEN is for other user defined types where more than one doc is allowed. type = TEXT covers text documents, telex, email etc. General document type. Expect to have multiple document keys for each type e.g. type = DOCU covers all the standard documents type = GEN is for other user defined types where more than one doc is allowed. type = TEXT covers text documents, telex, email etc. Available values: 'DOCU'='Documents', 'GEN'='General'.
  Description *(nillable: true, string Min: 1, Max: 35)* - Description of the document type e.g Bill of lading, Airway Bill, Bill of Exchange , Invoice etc.
