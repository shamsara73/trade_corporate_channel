ProductGroup *()* - Product group maintenance: Purpose: Allows details of Product groups to be added, updated or deleted.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  GroupID *(string Max: 20)* - Group ID.
  Description *(string Max: 65)* - Event group description.
  Products *()* - 
    Product [repeating] *(string Max: 4)* - Product code mapped in event group.
