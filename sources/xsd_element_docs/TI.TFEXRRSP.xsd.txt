TFEXRRSP *()* - Purpose: Incoming response to an event step verification request.
  Context *()* - The Context data of the message is used to provide basic information about the Customer, References, Team and the Product and Event that the message relates to.When creating a new master or event from a TFRCVDOC these fields are used to determine either the type of the new master this message creates, or the master against which a new event is to be created. For other Incoming messages it is the message type itself and master reference that is used to determine the event to be created. e.g.: TFILCAPP will create an Import LC - Issue event; TFCOLCOR for an existing Collection will create a Collection correspondence event against the specified Master.
    Branch *(nillable: true, string Min: 1, Max: 8)* - The input branch for the transaction.
    Customer *(nillable: true, string Min: 1, Max: 20)* - Sender's customer mnemonic.
    CustomerSwiftAddress *(nillable: true, string Max: 14)* - The SWIFT BIC of the customer sending the instruction.
    Product *(string Max: 4)* - TI Plus Product code associated with the event is to be created  e.g. - ICC - Inward documentary - OCC - Outward documentary - IDC - Inward documentary - ILC - Import LC - ELC - Export LC.
    Event *(string Max: 4)* - Code of the event to be created e.g. - ISI - Issuance - COR - Correspondence.
    OurReference *(nillable: true, string Min: 1, Max: 20)* - Bank's Master reference for this transaction (if known).
    TheirReference *(nillable: true, string Min: 1, Max: 34)* - Sender's reference for this transaction (if known).
    Team *(nillable: true, string Min: 1, Max: 15)* - Team to which the transaction should be assigned.
    BehalfOfBranch *(nillable: true, string Min: 1, Max: 8)* - The behalf of branch for the transaction.
    BehalfOfBranchSwiftAddress *(string Max: 14)* - The SWIFT BIC of the Behalf of branch of the transaction.
    TemplateIdentifier *(string Max: 35)* - The Deal template reference upon which the transaction is based.
    EventReference *(string Max: 6)* - Event reference consisting of a prefix and a number.
    Step *(nillable: true, string Min: 1, Max: 15)* - ID of the step to be enriched  TSDS-264 (PG).
    SubsidiaryMasterPrefixAndSerial *()* - The subsidiary master prefix and serial number.
      MasterPrefix *(nillable: true, string Min: 1, Max: 3)* - Master reference prefix.
      MasterSerialNumber *(nillable: true, int)* - Master reference serial number. Available Values: 0 to 99999999
    ExchangeNonAutoComplete *(logical)* - Whether the exchange step always requires user intervention. Boolean values.
