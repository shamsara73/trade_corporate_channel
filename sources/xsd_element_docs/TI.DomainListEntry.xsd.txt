DomainListEntry *()* - Domain list definition. Used to define domain list values used by the bank for certain fields. This allows the bank to define additional domain list values that are associated with an underlying behaviour.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Type *(string Max: 1)* - Domain list type. presenter's action 'E' and 'O', added 'Q': Export open account payment action, added 'S': Export open account payment request action, renamed 'A', added 'D': Export open account payment request response, 'G': Export open account payment response action. Available values: 'C'='Claiming bank's action', 'Q'='Export open account payment action', 'S'='Export open account payment request action', 'D'='Export open account payment request response action', 'G'='Export open account payment response', 'F'='Export open account presenter's action', 'O'='Import open account payment action', 'E'='Import open account presenter's action', 'A'='Import open account response action', 'Y'='Payment action', 'P'='Presenter's action', 'B'='Reimbursement payment action', 'R'='Response action', 'T'='Transfer presenter's action'.
  Code *(string Max: 3)* - Domain list code.
  Name *(string Max: 35)* - Domain list name.
  Behaviour *(string Max: 1)* - Domain list behaviour. Differs according to the domain list type. This specifies the underlying behaviour that the domain list selection will invoke. Claiming bank's action. Available values: 'D'='Sender has debited our account', 'F'='Request acceptance', 'O'='Other', 'P'=Request payment. Presenter's action. Available values: 'A'='Request authorisation to pay', 'D'='Sender has debited our account', 'F'='Request acceptance', 'O'='Other', 'P'='Request payment', 'R'='pay and claim reimbursement', 'S'='Documents sent on approval'. Response action. Available values: 'A'='Advice of discharge', 'B'='Advice of payment', 'D'='Documents received', 'G'='General', 'I'='Invoices received', 'M'='Maturity', 'P'='Authorisation to pay', 'R'='Refusal'. Payment action. Available values: 'T'='Accept', 'c'='Adjust maturity', 'K'='Approve authorisation request', 'A'='Await documents', 'I'='Await replacement invoices', 'B'='Claim reimbursement', 'n'='Finance offer', 'F'='Forward documents only', 'Y'='General request to applicant', 'H'='General request to issuer',  'Z'='General request to presenter',  'a'='General request to transferee',  'V'='Issue trust receipt', 'W'='Issue trust receipt loan', 'C'='Pay and claim reimbursement', 'P'='Pay', 'M'='Pay at maturity', 'b'='Pay from suspense', 'D'='Pay with discrepancies', 'X'='Pay with financing', 'L'='Refuse authorisation request', 'G'='Refuse documents', 'R'='Reject', 'Q'='Reject and claim refund', 'x'='Repay finance', 'U'='Request acceptance', 'N'='Request approval from applicant', 'J'='Request authorisation to pay', 'E'='Request payment', 'r'='Reverse payment', 'S'='Send documents on approval'.
  LinkedCode *(string Max: 3)* - Linked code. The value to be set in an associated domain list e.g. the 'Payment action' list value that is to be set when a Bank defined 'Presenter's action' domain list value is selected.
