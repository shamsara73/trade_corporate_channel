ChargePercentageSchedule *()* - Charge percentage schedule maintenance.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  Branch *(nillable: true, string Min: 1, Max: 8)* - The branch to which this percentage schedule applies (optional).
  Customer *()* - The customer to which this percentage schedule applies (mandatory).
    SourceBankingBusiness *(nillable: true, string Min: 1, Max: 8)* - Source banking business.
    Mnemonic *(nillable: true, string Min: 1, Max: 20)* - Customer mnemonic. Used to identify parties in a transaction e.g. - Applicant  or Beneficiary for Import and Export LCs and Guarantees Issued/Received - Drawer or Drawee for Outward and Inward Collections - Consignee(Importer) for shipping guarantees.
  Percentage *(nillable: true, decimal TotalDigits: 17, FractionDigits: 2)* - The default percentage applied to charge types/products/events not specified separately.
  UseChargeType *(logical)* - flag indicating whether this percentage schedule is mapped to specific charge types. Maps to charge types are stored even when not in use, hence need for this flag. Boolean values.
  UseProductEvent *(logical)* - flag indicating whether this percentage schedule is mapped to specific products and/or events. Product/event maps are stored even when not in use, hence need for this flag. Boolean values.
