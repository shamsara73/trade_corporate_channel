DocumentOfTitleDefinition *()* - Document of title definition maintenance.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Code *(string Max: 3)* - Document of Title Definition code.
  RequiresReturn *(logical)* - Indicates if requires return of document. Boolean values.
  DocumentFields *()* - 
    DocumentField [repeating] *()* - List of definition of a field in a Shipping Guarantees document of title. Used in DocumentOfTitleDefinition.
      FieldType *(string Max: 1)* - Available values: 'D'='Date', 'I'='Integer', 'B'='Logical', 'A'='Money', 'T'='Text'.
      Title *(string Max: 35)* - The title or name of the field. This is the caption used as a label for the field in the interface.
      Mandatory *(logical)* - Whether the field is mandatory or not. Boolean values.
