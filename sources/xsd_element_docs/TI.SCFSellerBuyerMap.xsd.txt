SCFSellerBuyerMap *()* - Seller buyer map. Purpose: Allows seller buyer relationship details to be added, updated or deleted.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Seller *()* - Seller.
    SourceBankingBusiness *(nillable: true, string Min: 1, Max: 8)* - Source banking business.
    Mnemonic *(nillable: true, string Min: 1, Max: 20)* - Customer mnemonic. Used to identify parties in a transaction e.g. - Applicant  or Beneficiary for Import and Export LCs and Guarantees Issued/Received - Drawer or Drawee for Outward and Inward Collections - Consignee(Importer) for shipping guarantees.
  Buyer *(nillable: true, string Min: 1, Max: 20)* - Invoice buyer.
  Limit *()* - Limit.

    Currency *(nillable: true, string Min: 1, Max: 3)* - Currency.

  Recourse *(logical)* - Indicates whether invoices from the buyer are with recourse or not. Boolean values.
  MaximumPeriod *()* - Maximum period. Used to validate whether the settlement date of the invoice is within the agreed term and therefore eligible for drawdown or discounting.
    TenorDays *(nillable: true, int)* - Tenor element of the term.
