CustomerMnmChange *()* - Customer mnemonic change Purpose: Allows Customer mnemonic to be updated ( where customer details are held at the main banking entity level ).
  MaintType *(string Max: 1)* -  Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  SourceBankingBusiness *(nillable: true, string Min: 1, Max: 8)* - Source banking business of the customer.
  OldCustomerMnemonic *(nillable: true, string Min: 1, Max: 20)* - CustomerMnemonic.
  NewCustomerMnemonic *(nillable: true, string Min: 1, Max: 20)* - Customer mnemonic.
