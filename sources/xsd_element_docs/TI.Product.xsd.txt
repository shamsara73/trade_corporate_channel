Product *()* - Product option maintenance.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  Code *(string Max: 4)* - Code Internal 4 char code - immutable, never seen by users used, in particular, for showing correct input screens.
  DefaultLongName *(string Max: 60)* - Long name Name displayed in configuration stage.
  DefaultShortName *(string Max: 10)* - Short name Name displayed in menus.
  Suppress *(logical)* - Used to suppress display of exemplar in File/New. Boolean values.
  SuppressHiddenProduct *(logical)* - Used to control suppress display of exemplar other than in File/New. Boolean values.
