SCFProgramme *()* - Supply chain finance programme. Purpose: Allows SCF programme details to be added, updated or deleted.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  ProgrammeID *(string Max: 35)* - The ID for this supply chain finance programme.
  ProgrammeDescription *(string Max: 60)* - The name for this supply chain finance programme.
  Customer *()* - 
    SourceBankingBusiness *(nillable: true, string Min: 1, Max: 8)* - Source banking business.
    Mnemonic *(nillable: true, string Min: 1, Max: 20)* - Customer mnemonic. Used to identify parties in a transaction e.g. - Applicant  or Beneficiary for Import and Export LCs and Guarantees Issued/Received - Drawer or Drawee for Outward and Inward Collections - Consignee(Importer) for shipping guarantees.
  Type *(nillable: true, string Min: 1, Max: 1)* - The type for this supply chain finance programme. Indicates whether Invoices created under the Supply Chain Finance Programme are  buyer or seller centric. Available values: 'B'='Buyer centric', 'S'='Seller centric'.
  SubType *(nillable: true, string Min: 1, Max: 10)* - The sub-type for this supply chain finance programme.
  CreditLimit *()* - The credit limit for this supply chain finance programme.
    Amount *(string Max: 22)* -

  Status *(nillable: true, string Min: 1, Max: 1)* - Programme status. Available values: 'A'='Active', 'B'='Blocked', 'I'='Inactive', 'R'='Referred'.
  StartDate *(nillable: true, date)* - Programme start date.
  ExpiryDate *(nillable: true, date)* - Programme expiry date.
  Narrative *(string Max: 6700)* - Narrative.
  FinanceProductType *()* - The Finance Product Type to be used when creating seller or buyer centric finance.
    Product *(string)* - Product.
