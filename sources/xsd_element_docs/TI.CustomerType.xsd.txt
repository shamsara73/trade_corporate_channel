CustomerType *()* - Customer type maintenance Purpose; Allows Customer types to be added, updated or deleted.
  MaintType *(string Max: 1)* - Maintenance type. Available values: 'F'='Define', 'D'='Delete', 'A'='Insert', 'U'='Update'.
  MaintainedInBackOffice *(logical)* - Optional. Indicates if the item is maintained in the Back Office. If so, the MaintainedInBackOffice flag is set on the corresponding Static data item and it is read-only in TI. Boolean values.
  Type *(nillable: true, string Min: 2, Max: 8)* - Customer type code.
  Description *(string Max: 35)* - Customer type description.
  Qualifier *(nillable: true, string Min: 1, Max: 1)* - Customer qualifier C - Customer/Corporate N - Bank B - Correspondent bank. This identifies a customer as being either a bank or customer/corporate or correspondent bank. Available values: 'N'='Bank', 'B'='Correspondent', 'C'='Customer/Corporate'.
  SuppressLimitCheck *(logical)* - Whether limit checking is required for this customer type. Boolean values.
